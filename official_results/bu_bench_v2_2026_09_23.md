# BU Bench V2: September 23, 2026 snapshot

This freezes the 37 costed model configurations in Gregor's September 23 comparison and adds Xiaomi MiMo V2.6 Flash/Pro and Mercury 2.5, for 40 points. Each point represents the historical 60-task cut. The current encrypted 200-task benchmark, incomplete runs and alternate experimental harnesses are not mixed into this chart.

## Score and cost

- **Score:** mean final weighted findings rubric credit, scaled to 0–100, after the judge's global penalties. It is not the percentage of tasks fully solved. Legacy records call this field `scores.score`; newer records use `scores.findings`.
- **Cost:** mean recorded agent cost across the 60 selected task results. Legacy records use `metrics.cost`; newer ones use `result.metrics.cost_usd`. These historical values reflect provider routes, then-current prices, reasoning settings, cache usage and time spent on failed tasks. They exclude judge and infrastructure cost and costs from discarded/replaced attempts. They are not fresh price estimates or all-in costs.
- Points are historical API policies, not local benchmarks of downloaded open-weight checkpoints. Native diffusion, speculative decoding, hardware and token throughput are not inferred from cost.
- No confidence intervals or paired significance tests are supplied. In particular, the 0.57-point MiMo Flash/Pro difference is not evidence of a stable ranking.

## Frozen cohort selection

The JSON lists the selected evaluation IDs and authenticated Laminar source links for every point. Legacy cohorts retain the existing result snapshots instead of selecting a best or newest replicate. No task text, expected answers, judge prose, screenshot payloads or private trajectories are published.

## Reproduce the plot

From the repository root:

```bash
uv run --group plots python generate_v2_plot.py
```

The script reads only the frozen aggregate JSON and the bundled Geist Mono font, and produces light/dark PNG and SVG files under `official_plots/`. It requires no service credentials and launches no model evaluations. Numbers identify the same rows on the scatterplot and table. The dashed line connects configurations for which no cheaper plotted configuration has a higher mean score; it does not account for statistical uncertainty.
